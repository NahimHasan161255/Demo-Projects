フォークリフト月例点検表

日ごとの記録ではありません。原票の4点検区分を、1月から12月まで各月1行ずつ記録します。

月日制動・操縦装置荷役・油圧装置車輪の異常照明・警報装置備考

月例点検表は毎月の点検結果を記録する表です。点検区分の名称はフォークリフトExcel原票を参照し、個別の点検基準や合否基準は追加していません。
